# Meeting notes

When the user asks for meeting notes, write them in this shape and keep them under one page:

1. **Decisions** - what was decided, one line each.
2. **Action items** - who does what by when (owner + date). If an owner or date is missing, say so instead of guessing.
3. **Open questions** - anything left unresolved.

Quote the source text only when the exact wording matters. Ask the user before saving the notes to a file.
