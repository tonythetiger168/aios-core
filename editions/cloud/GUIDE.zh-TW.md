# AIOS Cloud 使用說明

> **尚未推出。** 這份文件說明 Cloud 的規劃與收費，現在還不能註冊。需要現在就用的話，請從 Lite（不需要 GPU）或 Server 開始，同一份 `policy.toml` 之後可以沿用。

由我們代管 AIOS，你不用買顯示卡、不用維護伺服器。適合代理數超過一台 Server（約 5,000 個），或 GPU 一天用不到約 8 小時、租比買划算的團隊。

其他產品線與完整收費表見 [../README.zh-TW.md](../README.zh-TW.md)。

## 收費

| 項目 | 費用（美金） |
|---|---|
| 月費 | **US$25／人／月** |
| 包含的執行次數 | 每人每月 2,000 次，全組共用（例如 10 人 = 每月 20,000 次） |
| 超過的部分 | 每 1,000 次 **US$10** |
| 模型 | 預設自帶 API key（BYOK），模型費用你直接付給供應商，我們不轉賣 token |
| Enterprise | 報價，建議 US$20,000／年起 |

- **一次執行**＝一個任務從頭到尾跑完。超過 20 次模型呼叫的任務，每多 20 次多算一次；被政策擋下的執行不計費。
- 例：10 人團隊一個月跑 25,000 次 → 月費 US$250，超過 5,000 次 → US$50，合計 US$300。
- 由我們代管模型（不用自帶 key）的加價方式還在評估。

## 規劃中的內容

- Team 的全部功能：SSO 與角色、Postgres、多台 worker、審計匯出、機密管理、集中管理的政策與技能
- 每個組織的資料以資料列層級權限隔離
- 代理執行的程式碼在 microVM 裡隔離，外部工具的網路只能連到允許的主機
- 用量與帳單頁面

## 和本機產品線的差別

| | 本機（Lite／Personal／Workstation／Server） | Cloud |
|---|---|---|
| 資料在哪 | 你的機器 | 我們的雲端 |
| 硬體 | 自備 | 不需要 |
| 安全功能 | 全部免費 | 全部包含 |
| 計費 | Core 免費；Team 每人每月 US$15 | 每人每月 US$25，含執行次數 |

資料不能離開公司的話，請用 Personal、Workstation 或 Server。
